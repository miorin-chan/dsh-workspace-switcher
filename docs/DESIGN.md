# 工作区切换器设计

## 入口与视图

插件通过 `shell.overlay` 提供自己的浏览器，使用 DSH 的工作区和会话快照、实时会话状态、消息内容搜索和导航。
弹窗负责列表、行样式、搜索、视图选项和焦点。
DSH 内置侧栏继续使用自己的组件、分组和行扩展。

| 入口 | 打开时的视图 |
| --- | --- |
| `Mod+K` | 平铺会话。 |
| `Mod+Shift+K` | 上次选择的工作区分组，默认工作区树。 |
| 新会话页的 `Mod+Shift+K` | 同一工作区分组，只显示可选工作区。 |

弹窗打开时聚焦常开的搜索框，旁边以图标提供视图选项和可用的新建工作区操作。
视图菜单用图标和名称标示分组，在当前项显示选中勾。
Esc 先关闭菜单并将焦点还给视图按钮。搜索命中文件夹时显示其子树，也保留匹配项的祖先。
会话浏览合并标题、路径和消息正文命中。
DSH 默认关闭内容搜索（`session-query-sqlite` 的 `openAt: never`）。
内容搜索被部署禁用或请求失败时，弹窗与内置侧栏一致：不显示提示，只保留本地命中。
在 `Mod+Shift+K` 的切换器中，空格展开或折叠聚焦的工作区行。
浏览时回车在该工作区新建会话，复用行尾按钮的权限检查。
焦点在搜索框内时，空格输入查询，回车激活高亮行。
在 `Mod+Shift+K` 的切换器中，行背景高亮跟随光标，不标记当前选择。
新会话页用对勾标记当前工作区，选择已登记的工作区时调用 Hero 的 `onPick`，复用其草稿和 Agent preset 流程。
紧凑工作区标签继续提供五行最近使用列表及展开入口。

弹窗只记住明确选择的非平铺分组，偏好保存在浏览器本地，独立于侧栏。
已保存的分组不可用时，弹窗打开工作区树。
当前查询、键盘高亮和各分组的展开状态由当前弹窗实例管理。

`Mod+K` 的当前会话用行首细线标记，键盘光标用整行高亮。
平铺视图未搜索时，第一次按方向键从当前会话移动一行，到边界即停。
如果当前会话不在结果里，向下从首行开始，向上从末行开始。
查询有结果时，键盘光标从默认的首个匹配项移动。
光标跨出可视区时，列表立即滚动到最近的可见位置。

## 上一个会话

Ctrl+Tab 按下时直接打开本窗口上一个实际显示的常规会话，可跨工作区。
历史保存在当前窗口的插件实例中，最多记录 32 个会话 ID，按实际访问顺序去重。
跳过空会话、子代理、归档及已不可用项。没有候选时不导航。
macOS 和 Windows Desktop 默认绑定 Ctrl+Tab。
终端聚焦或打开模态控件时不处理切换。

## 分组与行操作

工作区分组包括平层工作区和按已登记祖先组织的工作区树。
选区模式只提供工作区分组。会话浏览的视图菜单使用 DSH Web 的共享 `Menu` 和图标，依次呈现分组、排序与归档筛选。
排序和归档筛选由弹窗保存。平铺、工作区和未分组会话各自保存手动顺序。
手动模式下可拖动同组会话，也可选中会话后用上移、下移按钮。
切换归档筛选会保留隐藏会话的排序记录。归档筛选同时应用到列表和搜索结果。
以真实会话或工作区作为目标，行内省略号通过 `contextMenu.button` 创建，右键和 Shift+F10 通过 `useContextMenu` 绑定。
桌面端在悬停、键盘聚焦或行菜单打开时显示行内操作区，
用「更多 → 归档／取消归档 → 置顶／取消置顶」替换会话行尾的时间和置顶标记。
归档行保留恢复操作。触屏端从更多菜单提供归档等操作，已置顶的会话额外保留取消置顶按钮。
快捷按钮解析 DSH 注册的同一菜单动作，复用权限、归档确认和操作反馈。
会话标题溢出时，悬停沿用官方行的滚动及边缘渐隐，离开时复位。
系统开启减少动态效果时直接显示标题末尾。
选区模式的行只用于选择工作区。会话状态沿用官方行的优先级和共享状态点。
内置工作区树使用官方最近祖先算法，并保留 UNC 共享根和同路径别名的归属规则。

## 相对内置侧栏的改良

弹窗总体上沿用内置侧栏的行为。下面这些地方是有意偏离原生界面的设计改良，升级 DSH 时应保留，不必向原生行为回调。

### 子工作区与会话之间的分隔线

内置侧栏展开一个工作区时，先列出子工作区，再列出它自己的会话，两组之间没有分隔。
子工作区也展开时，它的会话后面紧接着就是父工作区的会话，两者只差一级缩进，很难看出子树在哪里结束。
弹窗保留同样的顺序，但只要一个分支当前显示的内容里同时有子分支和会话，
就在它自己的第一条会话前画一条细线，颜色与缩进竖线相同。
判断只看搜索和归档筛选后的可见结果，与子工作区是否折叠无关，所以展开或收起子工作区时分隔线不会出现或消失。
分隔线只是装饰元素，不参与方向键顺序，也不进入树的无障碍结构。
手动排序时，分隔线也标出了会话拖动不能越过的边界。

## 验收

- 确认两种浏览入口的起始视图、选区模式、查询、方向键、视图切换与分组记忆。
- 验证 Ctrl+Tab 按下即切换，并在最近两个会话之间往返。
- 验证旧分组偏好回到工作区树，以及平层工作区偏好在页面刷新后仍有效。
- 展开一个同时含子工作区和会话的工作区，确认分隔线位于子工作区块之后、自身会话之前，
  折叠子工作区时位置不变，方向键跳过分隔线。
