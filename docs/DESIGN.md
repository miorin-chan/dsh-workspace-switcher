# 工作区切换器产品设计

## 要解决的问题

会话和工作区增多后，用户在窄小的侧边栏里反复滚动定位会话或跨工作区创建会话效率低，
也缺乏类似命令面板的键盘全局检索、工作区树快速穿梭和窗口内一键切回上一会话的能力。
本插件在保留内置侧栏职责的前提下，提供统一的键盘驱动检索与工作区切换弹窗。

## 目标体验与边界

### 入口与视图

| 入口 | 打开时的视图 |
| --- | --- |
| `Mod+K`（Web 端亦可用 `Mod+Alt+K`） | 平铺会话。 |
| `Mod+Shift+K` | 上次选择的工作区分组，默认工作区树。 |
| 新会话页的 `Mod+Shift+K` 或工作区标签「全部 N 个」 | 同一工作区分组，只显示可选工作区。 |

- **常开搜索与视图选项**：弹窗打开即聚焦搜索框，旁边提供视图选项菜单与可用的新建/添加工作区入口；
  视图菜单以图标和名称标示分组、排序与归档筛选，并在当前项显示选中勾；Esc 先关菜单并将焦点还给视图按钮，再按关闭弹窗。
- **搜索与导航**：搜索命中文件夹时显示其子树并保留匹配项祖先；会话浏览合并标题、路径、
  工作区、会话 ID 与消息正文命中（部署关闭或失败时不提示，只保留本地命中）。
  `Mod+Shift+K` 浏览器中，焦点在搜索框内时空格输入查询、回车激活高亮行；聚焦工作区行时空格展开或折叠，
  回车在该工作区新建会话（选区模式下回车为当前草稿选择工作区）。
- **记忆与键盘光标**：弹窗仅记住明确选择的非平铺分组（独立于内置侧栏保存在本地，
  旧值不可用时回退工作区树）；`Mod+K` 用行首细线标记当前会话、整行高亮标示键盘光标，
  未搜索时首次方向键从当前会话移动一行，有结果时从首条匹配移动，跨出可视区即刻滚动对齐。
  新会话页紧凑工作区标签继续提供最近五个工作区列表及展开入口。

### 上一个会话

- 默认绑定 `Ctrl+Tab`（macOS / Windows 桌面端；其他平台可在快捷键设置自行绑定），
  按下即切到本窗口上一个实际显示的常规会话并可往返。
- 历史按窗口记录最近 32 个实际访问过的常规会话，跳过空会话、子代理、归档与已不可用项，无候选时不导航；
  终端聚焦或打开模态控件时不拦截按键。

### 分组、排序与行操作

- 支持平铺、工作区与工作区树分组，以及手动排序（平铺、工作区、未分组各自保存，支持拖拽与上移/下移按钮）和归档筛选；
  切换归档筛选保留被隐藏会话的排序记录。
- 桌面端在悬停、键盘聚焦或行菜单打开时显示快捷操作（更多、归档/取消归档、置顶/取消置顶）替换行尾时间戳；
  支持右键、省略号与 `Shift+F10` 打开与内置侧栏一致的操作菜单并复用权限与确认流程；
  标题溢出时沿用原生悬停滚动（减少动态效果时直接显示末尾）。

### 相对内置侧栏的改良

- **子工作区与会话之间的分隔线**：工作区同时显示子工作区和自身会话时，在自身第一条会话前画一条与缩进竖线同色的细线，
  解决折叠/展开子工作区时缩进相近导致边界不清的问题；分隔线判断仅基于过滤后的可见结果、
  不随子工作区折叠出现或消失，只作视觉与拖拽排序边界，不参与方向键导航或无障碍树。

## 成功标准

| 场景 | 可观察结果 |
| --- | --- |
| 三种入口与起始视图 | `Mod+K` 打开平铺会话、`Mod+Shift+K` 打开上次非平铺分组、新会话页进入只选工作区模式且已选工作区带勾选。 |
| 搜索、展开与光标移动 | 搜文件夹保留子树与祖先；方向键从当前会话或首匹配平滑移动；`Esc` 优先关闭视图子菜单再关闭弹窗。 |
| 偏好记忆与回退 | 刷新页面后，非平铺分组偏好（如平层工作区）与手动排序、归档筛选保持；不可用旧分组回退工作区树。 |
| `Ctrl+Tab` 上一会话切换 | 按下即跳至本窗口上一常规会话，再按往返；不切入空会话、子代理或已归档会话。 |
| 子工作区与会话分隔线 | 同时可见子工作区和自身会话时，分隔线稳定位于子工作区块后、自身首条会话前，方向键自动跳过。 |
| 行内操作与停用恢复 | 右键、`Shift+F10` 或行内按钮可完成归档/恢复与置顶；停用插件后快捷键与弹窗不再拦截原生流程。 |

实现说明与接口核对从[项目文档索引](README.md)查阅。
