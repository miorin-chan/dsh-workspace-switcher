# 工作区切换器设计

## 侧栏浏览器的两种呈现

侧栏和快捷键弹窗呈现同一个会话与工作区浏览器。
两处使用同一套分组、排序、归档筛选、搜索结果、行组件和操作入口。
图标、状态点、缩进、标题和时间的显示、悬停卡、行按钮、右键菜单，以及由插件注册的行装饰和操作，都由浏览器的原有组件提供。
**视图选项**和**新建工作区**沿用侧栏的菜单、按钮和目录流程。
目录流程不可用时，两处都由浏览器决定入口是否显示。

弹窗只负责外框、初始视图、顶部搜索、焦点和关闭。
搜索框打开时获得焦点，始终可用，清空后回到当前分组。
视图选项和新建工作区在有查询时仍可使用。
搜索沿用浏览器的结果、索引及归档筛选规则。打开会话或完成新会话选区后关闭弹窗。
展开分组、切换视图或打开某项操作时，弹窗提供这项操作所需的交互空间。
Esc 先交给最上层的菜单或对话框，再由弹窗处理。
底部省略键盘说明。

| 入口 | 打开时的视图 |
| --- | --- |
| `Mod+K` | 浏览器的平铺会话列表。 |
| `Mod+Shift+K` | 弹窗上次选用且当前可用的工作区分组。首次使用时采用 DSH 内置的**工作区树**。 |
| 新会话页的 `Mod+Shift+K` | 同一工作区分组进入选区模式。目录仍可展开，选择已登记的工作区时调用新会话页的 `onPick`。 |

视图选项在弹窗开启期间即时切换列表，两种快捷键打开后都可使用同一菜单。
弹窗独立记住上次明确选择的非平铺分组 ID，跨关闭、重新打开和页面重载保留。
用 `Mod+K` 进入平铺视图或在菜单中切到平铺视图，都保留此前记住的工作区分组。
侧栏当前分组和弹窗记忆各自更新。工作区与会话数据、用户可见的操作结果、排序和归档设置由原浏览器共享。
搜索词和焦点属于当前弹窗实例。分组展开状态使用按呈现位置和分组 ID 区分的键，避免弹窗折叠分支时带动侧栏跳动。

新会话页的工作区标签保留独立的紧凑入口，仍可按名称和路径过滤、查看最近使用的五个工作区，并展开完整选择器。
该入口的选择动作和快捷键弹窗共用新会话页的选区回调，因而沿用现有草稿和 Agent preset 流程。

## 分组选择

`flat`、`workspace` 和 `workspace-tree` 沿用 DSH 的定义。
侧栏与弹窗的视图选项都从浏览器读取可用分组。
独立的文件目录分组通过同一入口出现，见[文件目录树设计](../../dsh-workspace-file-tree/docs/DESIGN.md)。
停用所选分组时，视图回到可用的内置工作区树，并保留上次明确选择的 ID。
重新启用后，下次用工作区快捷键可恢复该选择，除非用户已明确选了另一个分组。

## 客户端扩展点

DSH 的工作区 UI 提供一个可由侧栏和弹窗挂载的浏览器组件入口。
它复用原来的行、菜单、搜索、目录选择流程与扩展插槽。
呈现位置通过明确的参数传入显示形态、搜索常开、初始分组、选区模式及成功导航回调。
会话行的快捷操作、悬停内容和目录流程等插槽仍由浏览器拥有，并通过调用端获得渲染权限。
当两个浏览器实例同时挂载时，新建工作区和工作区管理对话框要由发起实例显示，避免两处同时响应同一交互请求。

共用浏览器具备分组扩展接口后，快捷键弹窗改用该入口，本地的会话列表、工作区树、搜索和管理操作随之迁移。
现有目录归并逻辑及其测试归入独立分组插件。
快捷键插件只依赖浏览器接口，文件目录分组按安装与启用状态出现。

## 验收

- 用相同分组、排序、筛选和查询对照侧栏与弹窗。
  检查画面与行交互，包括插件添加的图标及操作、右键菜单、归档、重命名和新建工作区。
- 分别使用两个快捷键，切换工作区分组后关闭并重新打开。
  重载页面后重复验证，检查弹窗记忆和侧栏各自的分组。
- 保持弹窗打开，启停文件目录分组插件，检查两处菜单和当前视图的更新、退回及再次打开后的恢复。
- 从新会话页确认目录展开、工作区选择以及原有草稿流程。
  通过键盘和鼠标检查焦点、嵌套对话框、浅色与深色主题。
