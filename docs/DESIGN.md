# 工作区切换器设计

## 入口与视图

插件通过 `shell.overlay` 提供自己的浏览器，使用 DSH 的工作区和会话快照、实时会话状态、消息内容搜索和导航。
弹窗负责列表、行样式、搜索、视图选项和焦点。
DSH 内置侧栏继续使用自己的组件、分组和行扩展。

| 入口 | 打开时的视图 |
| --- | --- |
| `Mod+K` | 平铺会话。 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 最近访问会话，分别前进或后退。 |
| `Mod+Shift+K` | 上次选择且当前可用的工作区分组，默认工作区树。 |
| 新会话页的 `Mod+Shift+K` | 同一工作区分组，只显示目录和可选工作区。 |

弹窗打开时聚焦常开的搜索框，旁边以图标提供视图选项和可用的新建工作区操作。
视图菜单用图标和名称标示分组，在当前项显示选中勾。
Esc 先关闭菜单并将焦点还给视图按钮。搜索命中文件夹时显示其子树，也保留匹配项的祖先。
会话浏览合并标题、路径和消息正文命中。
新会话页选择已登记的工作区时调用 Hero 的 `onPick`，复用其草稿和 Agent preset 流程。
紧凑工作区标签继续提供五行最近使用列表及展开入口。

弹窗只记住明确选择的非平铺分组，偏好保存在浏览器本地，独立于侧栏。
停用当前扩展时，弹窗立即回到工作区树。保存的 ID 仍可在扩展恢复时使用。
当前查询、选中行和各分组的展开状态由当前弹窗实例管理。

## 最近访问会话

快速切换复用浮层、会话行数据和原有的会话导航。
历史保存在当前窗口的插件实例里，最多记录 32 个会话 ID。
前台 Conversation 中实际显示的常规会话进入历史，记录按访问去重，可跨工作区。
选择时跳过空会话、子代理、归档及已不可用项。
候选快照在一次手势开始后固定顺序，高亮移动只改变选择。
松开 Ctrl 或按 Enter 时打开会话，Esc 和窗口失焦取消。
打开会话后，选中的会话通过正常的前台观测进入历史。

macOS 和 Windows Desktop 的默认绑定使用实际的 Ctrl。
两条命令通过快捷键注册表注册，跟随应用的冲突检查和自定义绑定。
Ctrl 松开由页面处理。macOS Desktop 在每次快捷键移动后等待 650 毫秒，松键未送达时提交当时的高亮。
持续按快捷键会重新计时。用方向键移动后改为手动确认。
手工绑定不含 Ctrl 的组合时，用 Enter 确认。
终端聚焦或打开其他模态控件时，切换器不打开。

## 分组接口

默认的工作区视图包括平层工作区和按已登记祖先组织的工作区树。
分组区同时列出客户端服务 `workspaceSwitcherGrouping` 的实时注册项。
选区模式只提供工作区分组。会话浏览的视图菜单使用 DSH Web 的共享 `Menu` 和图标，依次呈现分组、排序与归档筛选。
排序和归档筛选由弹窗保存。平铺、工作区和未分组会话各自保存手动顺序。
手动模式下可拖动同组会话，也可选中会话后用上移、下移按钮。
切换归档筛选会保留隐藏会话的排序记录。归档筛选同时应用到列表和搜索结果。
以真实会话或工作区作为目标，行内省略号通过 `contextMenu.button` 创建，右键和 Shift+F10 通过 `useContextMenu` 绑定。
桌面端在悬停、键盘聚焦或行菜单打开时显示行内操作区，
用「更多 → 归档／取消归档 → 置顶／取消置顶」替换会话行尾的时间和置顶标记。
归档行保留恢复操作。触屏端从更多菜单提供归档等操作，已置顶的会话额外保留取消置顶按钮。
快捷按钮解析 DSH 注册的同一菜单动作，复用权限、归档确认和操作反馈。
会话标题溢出时，悬停沿用官方行的滚动及边缘渐隐，离开时复位。
系统开启减少动态效果时直接显示标题末尾。
选区模式的行只用于选择工作区。会话状态沿用官方行的优先级和共享状态点。
内置工作区树使用官方最近祖先算法，并保留 UNC 共享根和同路径别名的归属规则。

扩展通过 Cordis 依赖该服务，再调用 `register({ id, label, project })`，把返回的注销函数交给自身的 effect。
`id` 稳定且唯一，保留 ID 为 `flat`、`workspace`、`workspace-tree`。
`label` 提供当前语言的显示名称。
`project` 接收按弹窗顺序列出的 `{ workspaceId, path }`，返回工作区及目录节点构成的森林。
工作区节点使用 `{ kind: 'workspace', workspaceId, children? }`，投影中每个输入工作区恰好出现一次。
合成目录使用 `{ kind: 'directory', key, title, path, children }`，`key` 在投影中唯一。
浏览器保留真实工作区的行操作，将未归属会话单独放在根部。
如果投影抛错或违反结构约束，弹窗显示工作区树和错误提示。

文件目录树由独立的 [dsh-workspace-file-tree](../../dsh-workspace-file-tree/docs/DESIGN.md) 注册，可独立启停。

## 验收

- 确认两种浏览入口的起始视图、选区模式、查询、方向键、视图切换与分组记忆。
- 用三个会话验证 Ctrl+Tab 正向、反向、松键确认、Esc 取消和最近两个会话间往返。
- 开关目录插件，验证弹窗菜单、回退和偏好恢复。
- 搜索含合成目录的分支，验证仍可选择真实工作区、打开会话和操作工作区。
