# 工作区切换器设计

## 入口与视图

插件通过 `shell.overlay` 提供自己的浏览器，使用 DSH 的工作区和会话快照、实时会话状态、消息内容搜索和导航。
弹窗负责列表、行样式、搜索、视图选项和焦点。
DSH 内置侧栏继续使用自己的组件、分组和行扩展。

| 入口 | 打开时的视图 |
| --- | --- |
| `Mod+K` | 平铺会话。 |
| `Mod+Shift+K` | 上次选择且当前可用的工作区分组，默认工作区树。 |
| 新会话页的 `Mod+Shift+K` | 同一工作区分组，只显示目录和可选工作区。 |

弹窗打开时聚焦常开的搜索框，旁边以图标提供视图选项和可用的新建工作区操作。
视图菜单用图标和名称标示分组，在当前项显示选中勾。
Esc 先关闭菜单并将焦点还给视图按钮。搜索命中文件夹时显示其子树，也保留匹配项的祖先。
会话浏览合并标题、路径和消息正文命中。
新会话页选择已登记的工作区时调用 Hero 的 `onPick`，复用其草稿和 Agent preset 流程。
紧凑工作区标签继续提供五行最近使用列表及展开入口。

弹窗只记住明确选择的非平铺分组，偏好保存在浏览器本地，独立于侧栏。
停用当前扩展时，弹窗立即回到工作区树。保存的 ID 仍可在扩展恢复时使用。
当前查询、选中行和各分组的展开状态由当前弹窗实例管理。

## 分组接口

默认的工作区视图包括平层工作区和按已登记祖先组织的工作区树。
菜单同时列出客户端服务 `workspaceSwitcherGrouping` 的实时注册项。
选区模式只提供工作区分组。

扩展通过 Cordis 依赖该服务，再调用 `register({ id, label, project })`，把返回的注销函数交给自身的 effect。
`id` 稳定且唯一，保留 ID 为 `flat`、`workspace`、`workspace-tree`。
`label` 提供当前语言的显示名称。
`project` 接收按弹窗顺序列出的 `{ workspaceId, path }`，返回工作区及目录节点构成的森林。
工作区节点使用 `{ kind: 'workspace', workspaceId, children? }`，投影中每个输入工作区恰好出现一次。
合成目录使用 `{ kind: 'directory', key, title, path, children }`，`key` 在投影中唯一。
浏览器保留真实工作区的行操作，将未归属会话单独放在根部。
如果投影抛错或违反结构约束，弹窗显示工作区树和错误提示。

文件目录树由独立的 [dsh-workspace-file-tree](../../dsh-workspace-file-tree/docs/DESIGN.md) 注册，可独立启停。

## 验收

- 确认两种快捷键起始视图、选区模式、查询、方向键、视图切换与分组记忆。
- 开关目录插件，验证弹窗菜单、回退和偏好恢复。
- 搜索含合成目录的分支，验证仍可选择真实工作区、打开会话和操作工作区。
