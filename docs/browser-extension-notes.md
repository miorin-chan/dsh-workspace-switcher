# 当前 DSH 接口核对

已连接的 DSH 0.2.2-rc.5 将会话和工作区浏览器注册到 `sidebar.workspaces`。
该插槽只向侧栏拥有者提供 `wide`、`expandSidebar` 和滚动绑定。
客户端的 `renderSlot` 限定于声明者授权的子插槽。
工作区包另外发布了 `workspace.picker`，可复用目录选择流程。
完整浏览器、视图选项和行操作由 `WorkspaceBrowser` 及其注册拥有。

`SessionGroupBy` 目前是 `flat`、`workspace` 和 `workspace-tree` 的封闭联合，`ViewOptionsMenu` 直接列出这三项。
搜索展开时原组件会隐藏部分顶栏动作。
把整块侧栏移到弹窗仍需为常开搜索、顶栏动作和弹窗独立分组状态提供参数。
如果两处同时挂载，还需明确目录流程和管理对话框的发起实例，当前请求源由侧栏注册共享。

因此，实现入口在 DSH 的工作区 UI 源码。
先从侧栏注册提取可在两个呈现位置使用的浏览器接口，再让同一组件的视图选项订阅分组注册表。
这两个扩展点可以分别验收。
先在侧栏和第二个浏览器实例中验证菜单、目录流和行扩展仍可用，再用文件目录插件验证分组即时注册和释放。
当前安装是打包后的 Desktop 应用，工作区内有对应的类型包和源码可供核对。
交付扩展点需要可构建的 DSH 源码检出及包含相应接口的构建。
